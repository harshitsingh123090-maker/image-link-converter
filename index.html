Colour-wise Upload

Images divided only by colour. Add a colour like Black, upload all images of that colour together, then add another colour like Blue and upload its images. Each image gets its own link, grouped under its colour.

🔀 Change order: Use ◀ ▶ buttons or drag an image, or press Shuffle this colour — links and CSV will follow this order. The number 1, 2, 3… on each image = Image 1, Image 2… in the CSV row.

Copy All (Colour-wise) copies tab-separated rows ready to paste into Excel / Flipkart / Amazon sheet: first cell is the Colour, then its links side-by-side across columns in the same row, one colour per line (no header). Download CSV (Colour-wise) gives the same row form with a header: Colour, Image 1, Image 2, … — one row per colour. Each colour block's Copy Links copies only that colour's links tab-separated in one row.
